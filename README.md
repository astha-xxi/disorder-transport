# Archived original 2-D experiment

These files preserve the original 192-run, 2-D study supplied for this project. They are not generated by the new 3-D solver. See `../../docs/original_study.md` for parameter provenance, interpretation, and caveats.

- `experiment_summary_corrected.csv`: 192 rows, one per generated landscape/realization.
- `quantum_transport_raw_data_corrected.csv`: 9,792 rows of time-series observables.
- `quantum_transport_corrected_notebook.ipynb`: original corrected computational notebook.
- `README_quantum_transport_corrected.txt`: original experiment notes.
